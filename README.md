## 🍽️ UT HallBites

UX Research · UX Design · Figma · HTML · CSS · JavaScript

UT HallBites is an independent summer project exploring how thoughtful UX and system design can address campus food waste and student food insecurity. The project moves through the full design process—from research and ideation to prototyping, development, and testing.

## 🌱 Project Overview

After uncovering the scale of food waste in campus dining systems alongside growing student food insecurity, I set out to imagine a more efficient and humane system for redistributing surplus meals.

The result is UT HallBites, a conceptual platform that transforms surplus dining hall food into affordable, student-centered meals.

This project was built as an interactive HTML demo to bring the concept to life and demonstrate how such a system could function in a real campus environment.

## 🧩 What It Does

UT HallBites simulates a streamlined experience where users can:

- Browse available surplus meals from dining halls
- View availability, timing, and pickup details
- Reserve meals in a simple, low-friction flow
- Understand real-time food availability through clear UI cues

The goal is to make accessing surplus food feel trustworthy, intuitive, and stigma-free.
